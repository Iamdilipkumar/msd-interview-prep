# MSD Enterprise Storage & DevOps Interview Prep

Focused preparation material for a senior Enterprise Storage & DevOps /
Infrastructure Engineering interview.

## How to use this tonight

1. Read [`01_TOMORROW_CORE_CRASH_COURSE.md`](01_TOMORROW_CORE_CRASH_COURSE.md).
2. Answer questions in
   [`02_TOMORROW_INTERVIEW_QUESTIONS.md`](02_TOMORROW_INTERVIEW_QUESTIONS.md)
   aloud before reading the answers.
3. Run [`03_MOCK_INTERVIEW_1.md`](03_MOCK_INTERVIEW_1.md).
4. Review weak areas in the crash course.
5. Run [`04_MOCK_INTERVIEW_2.md`](04_MOCK_INTERVIEW_2.md).
6. Before the interview, read only
   [`05_LAST_60_MINUTES.md`](05_LAST_60_MINUTES.md).

## Highest-priority topics

- Enterprise storage fundamentals
- NetApp / ONTAP concepts
- NFS / SMB / SAN / iSCSI / FC
- Snapshots / SnapMirror / SnapVault
- Storage performance and troubleshooting
- Backup, replication, RPO/RTO and disaster recovery
- AWS S3 / EBS / EFS / FSx
- Terraform
- Kubernetes/EKS storage
- Architecture and troubleshooting scenarios

## Important interview principle

Understand and explain the engineering reasoning. Do not fabricate production
experience.

If a scenario was learned through training or lab work rather than personally
owned in production, state that boundary clearly and then explain how you would
approach it technically.
